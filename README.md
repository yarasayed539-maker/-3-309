# DevHub - Component Library, Validation & Dynamic Data Table

An interactive website containing responsive layout components, user input validation using JavaScript, and a live data filtering table.

## Implemented Tasks

### Part 1: Form Validation (`validation.html`)
- Built a user registration form containing Name, Email, Password, Confirm Password, and Age fields.
- Applied JavaScript event handling on form submission (`preventDefault`).
- Implemented real-time inline error handling under each input field.
- Implemented pattern testing using Regex for email and minimum length checking for passwords.

### Part 2: Dynamic Table & Operations (`data.html`)
- Rendered table rows dynamically via JavaScript DOM manipulation (`document.createElement`).
- Added instant filter functionality on keypress without page reloads.
- Implemented column sorting algorithms (`localeCompare` for string names and numerical comparison for ages).

### Part 3: Deployment
- Version controlled and pushed to GitHub repository.
